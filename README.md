# Mobile - J2ME

Thumbnails for J2ME games (No-Intro "Mobile - J2ME"), laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails) (`Named_Snaps`), named after the No-Intro names up to the first bracket.

The snaps were taken with the FreeJ2ME libretro core in RetroArch: each game is launched on its own at the screen size its name gives (240x320 when it gives none), run for 900 frames and the last frame is kept, at the game's own resolution scaled 2x. Many games open on a language, sound or demo screen, which is what they show without a player. Games that stayed blank have no snap.
